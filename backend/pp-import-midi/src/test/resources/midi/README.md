Real MIDI files used as golden tests, both public domain, from the Mutopia Project (engraved with LilyPond):

- `bach-minuet-in-g.mid`: J. S. Bach, Minuet in G, BWV Anh. 114, https://www.mutopiaproject.org/ftp/BachJS/BWVAnh114/anna-magdalena-04/
- `schubert-impromptu-d899-3.mid`: F. Schubert, Impromptu in G-flat, D. 899 No. 3, https://www.mutopiaproject.org/ftp/SchubertF/D899/SchubertF-D899-3-Impromptu/

LilyPond names the first track "control track" and gives each voice its own track, named after its staff ("up:", "upII:", "down:", …).
